# .template.config (Phase 8)

`dotnet new` template configuration. `template.json` sets `sourceName: "TodoApp"`
(renames namespaces, projects, folders), short name `azure-starter`, and parameters:
`--include-functions`, `--include-signalr`, `--include-mobile`, `--entra-tenant-mode`,
`--no-sample`. A second item template `azure-module` scaffolds new modules.
